# Northline: fictional small-business website demo

Open `index.html` directly in a modern browser. It is one self-contained HTML file with inline CSS and JavaScript, no dependencies, fonts, images, external requests or build process.

Original fictional coworking brand, CSS workspace illustration, service/pricing cards, native accessible FAQ disclosure, responsive navigation, and a local enquiry preview using a native modal dialog. The menu exposes its expanded state; the modal has a labelled title and description, keyboard closing and native focus containment. The preview inserts user input as text, never HTML.

The visible banner and footer disclose the fictional portfolio nature and AI assistance. Prices, amenities and spaces are illustrative. There is no actual address, booking, payment, form transmission, analytics or persistent storage. No testimonials or client outcomes are claimed. Do not enter personal information into the demo.

Before publishing, visually inspect desktop and narrow/mobile widths, keyboard navigation, menu open/close, plan preselection, Escape, FAQ expansion and the preview’s “nothing sent” state. The source has no network delivery integration; a real client would separately agree the contact destination and privacy requirements.
